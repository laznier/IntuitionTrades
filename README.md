# Intuition Trades

This is a simple multi-page site demonstrating free stock analysis and forecast tools for traders.

Currently includes:

- **Weekly Stock Picks** – A section featuring the Top 3 Buys and Top 3 Shorts of the week.
- **Tools** – A collection of stock analysis tools available in individual folders (e.g., `stocks/`, `sentiment/`, `insider/`, `technical/`, `MACD/`, `ichimoku/`).
- **Tutorials Section** – Guidance and insights for using the tools.
- **Feedback Section** – Let us know how we can improve the website.
- **Newsletter Signup** – Users can sign up for a free weekly newsletter featuring the top stock picks by simply entering their name and email. Submissions will auto-send an email to the site owner.

## Local Development

1. Clone this repository or download the ZIP.
2. Open `index.html` in your browser to see the landing page.
3. Each tool resides in its own folder (e.g., `stocks/index.html` for the Stock Trend Forecast tool).
4. Optionally, host it locally (e.g., via a simple HTTP server) if needed.

## GitHub Pages Deployment

1. Push all files to a **public GitHub repository**.
2. Go to **Settings** > **Pages** in your GitHub repository.
3. Under "Branch," select `main` (or `master`) and then the `/ (root)` folder. Click **Save**.
4. Wait a few seconds; GitHub will give you a URL like `https://<username>.github.io/<repo-name>/`.
5. Open that URL in your browser. You should see the landing page.
