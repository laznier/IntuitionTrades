How to Play

Practice runs up to 10 Cover→Engage→Away→Vanished sequences. Each sequence follows:

  1. COVER
    Click the track under the current B/E prompt, then press C (Cover).
  2. NEGATE or AFFIRM
    • If the prompted track is not on B/E, press N (Negate) to skip.
    • Otherwise press A (Affirm) to move to Engage.
  3. AWAY
    Press W to send Birds Away. Must be inside the ICC circle or any radar wedge.
  4. KILL/DROP
    Press K to kill. Auto-kill after 6 s if you wait.

Scoring

  • +1 point for each correct Cover→Affirm→Away→Vanished sequence.
  • –1 point if Away misses (Bird Trashed).
  • –5 points for an ROE violation (Away before engaging).
  • 0 points for a correct Negate.

Hotkeys & Controls

  • R: Set new Bullseye at cursor and respawn tracks.
  • C: Cover
  • A: Affirm → Engage
  • N: Negate
  • W: Away (Birds Away)
  • K: Kill/Drop
  • Click/Drag: Draw BRAA line from your drag start to cursor
  • Right-click: Secondary select (show 2️⃣ card)
  • Mobile Buttons: Tap the onscreen buttons (C, A, N, W, K, R) to trigger the same hotkeys.
