Monte Carlo Risk Assessment Tool

This tool assesses stock risk using an advanced Monte Carlo simulation based on either a Heston or Jump‐Diffusion model. It fetches historical price data—and where available, realtime options data—to calibrate the model and display risk metrics such as Value at Risk (VaR) and Conditional VaR (CVaR).

Detailed Explanation

This tool uses Monte Carlo simulation to assess the risk of a given stock over a future time horizon. The user can select between two models:

  • Heston Model: Incorporates stochastic volatility by simulating not only the stock price but also its variance. Parameters include the mean reversion speed, long-run variance, volatility of volatility, and correlation between stock returns and volatility.
  • Jump-Diffusion Model: Extends the standard geometric Brownian motion by including jumps. This helps capture sudden large moves in the stock price. Parameters include jump intensity and the statistical properties of jump sizes.

Based on the historical price data (and, optionally, realtime options data via our liveoptions.js endpoint), the tool estimates the drift and volatility. For the Heston model, the initial variance is set using these estimates, and default calibration parameters are used (e.g., κ = 2.0, θ = volatility², ξ = 0.5, ρ = -0.7). For the Jump-Diffusion model, default jump parameters (e.g., λ = 0.1 jumps/year, average jump multiplier = 1.0 and jump volatility = 0.2) are applied.

The simulation generates a distribution of final prices at the target date. From this distribution, risk metrics are computed:

  • VaR (Value at Risk): The 5th percentile of simulated prices which indicates the worst expected loss over the period.
  • CVaR (Conditional Value at Risk): The average of the worst 5% outcomes, providing a measure of tail risk.

Users can adjust a slider to set a specific target price threshold and see the probability that the stock will close above that value. This interactive feature helps quantify potential upside versus downside risk.
